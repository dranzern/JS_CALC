# Calculadora Funcional en JavaScript 🧮

Una calculadora web interactiva construida con Vanilla JavaScript. Aunque mi enfoque principal está en el desarrollo Backend (Java/SQL), este proyecto refleja mi capacidad para estructurar lógica limpia, manejar flujos de control y resolver problemas algorítmicos en cualquier lenguaje.

**Características principales:**
* Lógica de operaciones matemáticas modular y estructurada.
* Manejo de casos borde (como divisiones por cero o entradas vacías).
* Código limpio y fácil de mantener.
